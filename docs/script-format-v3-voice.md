# 腳本格式補充說明 v3：配音

這份文件說明 `public/script.json` 在 v1、v2 之上**新增**的配音欄位。v1、v2 的欄位與規則全部保留不變，沒有 `voice` 欄位的腳本照常執行、只是沒有聲音。

讀者有兩位：

- **引擎 AI**：照這份文件實作配音播放、設定項目、開發者頁面與腳本檢查。
- **劇本 AI**：照這份文件在台詞上填 `voice` 編號，並產生音檔。

音檔要用誰的聲音、怎麼生成，**不在這份文件的範圍**。引擎只負責「有這個檔就播、沒有就安靜」。

---

## 設計原則

1. **任何 speaker 都可以配音，由劇本決定誰有聲音。** 格式上 `narrator`、`player` 與 `characters` 裡的角色都可以掛 `voice`，引擎一視同仁。《寫給未來的我》的選擇是：淑芬（`player`）與旁白不配音，只有別人會說話。其他專案可以全部配音。
2. **聲音不退化。** 文字會模糊、消失、變成注音，但別人說話的聲音永遠清楚。這是刻意的：玩家聽得見別人，卻讀不出自己寫的字。退化係數不套用在配音上，唯一的例外是 fx `muffle`（見下方）。
3. **缺檔不是錯誤。** 找不到音檔時安靜播過，不顯示任何錯誤，主控台也不要噴紅字。配音會分批補齊，遊戲在任何階段都要能跑。

---

## 新增欄位一覽

| 欄位 | 位置 | 說明 |
| --- | --- | --- |
| `voice` | 台詞（任何 speaker） | 這句台詞的音檔編號，對應 `public/assets/voice/{voice}.mp3` |
| `voice` | choice 那一行 | `prompt` 的音檔編號（prompt 是角色說的話時才用） |
| `truthVoice` | 物件 | 記憶對照時由 `memoryReview.speaker` 唸出 `truth` 的音檔編號 |
| `settingsDefaults.voiceVolume` | meta | 配音音量預設值 |

---

## 1. 台詞的 `voice`

```json
{ "speaker": "husband", "expression": "smile", "text": "妳的眼鏡在頭上。", "voice": "a1_s01_04_husband" }
```

### 編號規則

- 格式：`{場景id}_{兩位序號}_{角色id}`，例如 `a1_s01_04_husband`、`a4_s16_12_bride`。
- 序號是劇本 AI 編的，**不是**該句在 `lines` 裡的索引。之後插入或刪除台詞，已有的編號不變，只有新句子拿新號碼。引擎不要用索引去推檔名。
- 整份腳本的 `voice` 值**不可重複**。
- 分支台詞（有 `if` 的句子）照樣有自己的編號。
- 任何 `speaker` 的台詞都可以掛 `voice`。`narrator`、`player` 的編號角色段就寫 `narrator`、`player`，例如 `a1_s01_01_player`。本專案不會用到，但引擎要支援。

### 檔案位置

`public/assets/voice/{voice}.mp3`，找不到時再找 `.ogg`（規則與音樂相同）。單聲道、44.1 kHz 或 48 kHz，每句一個檔，句尾不留長靜音（由引擎控制停頓）。

### 播放行為

- 台詞開始顯示時播放，與打字效果同時開始。
- 玩家在聲音播完前點下一句：聲音在 0.1 秒內淡出停止，不要硬切也不要讓兩句重疊。
- **自動模式**：有配音的句子，等「聲音播完」和「文字打完」兩者都結束後，再加原本的停頓才往下走。沒有配音的句子維持原本的計時。
- **回上一句**：回到的那句如果有配音，重播一次。
- **略過**：略過中不播配音。
- **對話紀錄**：有配音的句子在紀錄裡顯示一個小喇叭，點了重播那一句。`log: corrupt` 的場景裡喇叭照樣出現，但紀錄文字照舊亂掉。
- 換場景時正在播的配音停止。
- 選項出現時，正在播的配音播完即可，不用停。

### 與 fx 的關係

| fx | 對配音的影響 |
| --- | --- |
| `muffle` | 套同樣的低通濾波與降低音量（與音樂的處理一致） |
| `repeat_line` | 重複顯示的那幾次，配音也跟著重播 |
| `name_fade`、`text_blur` | 不影響配音，聲音保持清楚 |
| 其他 | 不影響 |

## 2. choice 的 `voice`

`prompt` 是角色說的話時（例如「新娘：「媽，幫我扣項鍊好嗎？」」），可以在 choice 那一行掛 `voice`，選項出現時播放。`prompt` 是旁白描述時不掛。

```json
{
  "prompt": "新娘：「媽，幫我扣項鍊好嗎？」",
  "voice": "a4_s14_09_bride",
  "choice": [ ... ],
  "mode": "list"
}
```

選項本身的 `text` 是主角說的話，**本專案不配音**；格式上也不提供選項的 `voice`，選項是玩家的決定，不是聽的東西。

---

## 3. 物件的 `truthVoice`

記憶對照（v2 第 5 節）播到「由 `speaker` 說出 `truth`」那一步時，播放這個音檔。`inline` 與 `page` 兩種形式都適用；`page` 形式在每一列的 `truth` 旁放一個喇叭。

```json
{
  "id": "a1_phone",
  "truth": "照片下面還有一句：媽，十點喔，不要忘記。她沒有往下滑。",
  "truthVoice": "mr_a1_phone_daughter"
}
```

編號格式：`mr_{物件id}_{speaker}`。`description` 是淑芬自己看的，本專案不配音；格式上也沒有 `descriptionVoice`，之後有需要再加。

## 4. 設定

`meta.settingsDefaults` 新增一項：

| 設定 | 值 | 預設 | 設定畫面的文字 |
| --- | --- | --- | --- |
| `voiceVolume` | 0 到 1 | `0.9` | 配音音量 |

設定畫面裡配音音量與音樂音量分開兩條。音量 0 等於關閉配音，此時自動模式的計時照「沒有配音」處理。玩家改過後存在瀏覽器裡，跟其他設定一樣。

---

## 5. 開發者頁面：配音總表

引擎要提供一個開發者頁面（路徑由引擎 AI 決定，例如 `/dev/voice`，不要出現在遊戲選單裡），用來看配音進度與試聽。這一頁從 `script.json` 直接讀，不用另外的資料檔。

### 要有的東西

1. **總表**：每一列是一句有 `voice`（或 `truthVoice`、choice 的 `voice`）的台詞，欄位：編號、場景 id、角色、台詞文字、檔案狀態（有／缺）、播放鈕。檔案狀態用 `HEAD` 或 `fetch` 探測 `public/assets/voice/{voice}.mp3` 與 `.ogg`。
2. **統計**：總句數、已有音檔數、缺檔數，依角色分開統計。
3. **篩選**：依角色、依場景、只看缺檔。
4. **匯出配音清單**：一顆按鈕，下載 `voice-lines.json`，內容是陣列，每筆 `{ "id", "scene", "speaker", "text" }`，只含缺檔的句子（可以切換成全部）。這個檔會拿去餵語音生成工具。
5. **整場試聽**：選一個場景，依序播放該場景所有有音檔的句子，方便聽語氣是否連貫。

### 不用做的

不用在這一頁上傳音檔、不用做錄音功能、不用接任何語音服務。音檔由外部工具產生後放進 `public/assets/voice/` 即可。

---

## 腳本檢查要新增的項目（給引擎 AI）

`validateScript` 要能抓出：

1. `voice` 或 `truthVoice` 的值重複。
2. `voice` 掛在 choice 那一行但沒有 `prompt`。
3. `truthVoice` 掛在沒有 `truth` 的物件上。
4. 編號不符合 `{場景id}_{兩位序號}_{speaker}` 或 `mr_{物件id}_{speaker}` 的格式（警告）。

缺音檔**不是**腳本錯誤，檢查時不要讀檔案系統。

---

## 文字編輯模式

`voice`、`truthVoice` 是結構欄位，文字編輯模式裡不可修改。改了台詞文字之後編號不變，由外部工具比對文字決定要不要重新生成那一句。

---

## 劇本 AI 的填寫提醒

- 本專案：每一句 `speaker` 是角色的台詞都要填 `voice`，包括 `if` 分支句與結局場景；`player`、`narrator` 不填。
- 終幕的 `bride` 是佳穎，編號裡照寫 `bride`；生成時用與 `daughter` 同一個聲音。
- 填完後跑一次合併與檢查，確認編號沒有重複。

---

## 引擎實作補充（文件沒寫到的情況）

以下是引擎 AI 實作時自行決定的做法，劇本 AI 寫腳本、產生音檔時也請以這裡為準。

### 找檔案

- 建置時（以及 `npm run dev` 時）引擎會自動產生 `assets/voice/manifest.json`，列出 `public/assets/voice/` 裡實際存在的 `.mp3`、`.ogg`。遊戲只請求清單上有的檔案，所以缺檔時**完全不發請求**，主控台不會出現 404 紅字。
- 放進新的音檔後：本機開發立即生效；線上版重新部署（合併到 main）後生效。
- 萬一沒有 manifest（例如把 `dist/` 以外的東西直接放上主機），才退回逐一用 `HEAD` 試 `.mp3`、`.ogg`。

### 播放

- **音量**：配音另走一條音軌，有自己的音量（設定畫面「配音音量」），不受音樂音量與退化係數影響；`muffle` 會同時套在音樂與配音上。原本的「音量」改名為「音樂音量」。
- **內心獨白**（`player`）若有配音：獨白要等聲音播完才淡出、自動前進。
- **記憶對照 inline**：物件卡先出現，約 1.1 秒後 `truth` 開始打字時才播 `truthVoice`，與「說出真相」同步。
- **page 形式**：每列 `truth` 旁的喇叭只在音檔存在時顯示。
- **對話紀錄的喇叭**：只在那一句**有音檔**時顯示，還沒有音檔的句子不顯示，避免點了沒聲音。choice 的 `prompt` 不寫入對話紀錄（v1 起就是如此），所以它的配音不會出現在紀錄裡。
- **自動模式**：聲音和文字都結束後，再加原本的停頓（1.2 秒＋每字 0.07 秒）。
- **ui `log: corrupt`**：喇叭照常出現在留下來的句子上。

### 腳本檢查

- 文件列的四項都已實作；另外檢查 `settingsDefaults.voiceVolume` 必須是 0 到 1 的數字。
- 第 4 項（格式）以「（警告）」開頭列出：台詞的編號必須是 `{所在場景id}_{兩位序號}_{這句的 speaker}`；choice 的編號是 `{所在場景id}_{兩位序號}_{某個 speaker}`；`truthVoice` 是 `mr_{這個物件的id}_{某個 speaker}`。speaker 必須是 `narrator`、`player` 或 `characters` 裡的 id。

### 開發者頁面「配音總表」

- 網址：遊戲網址後面加 `?voice=1`（例如 `https://cathylab.github.io/dementia-game/?voice=1`）。開發者面板的「配音總表」按鈕也會在新分頁打開。遊戲選單裡沒有入口。
- 依文件用 `HEAD` 探測 `.mp3`、`.ogg`，所以**這一頁**的主控台會看到缺檔的 404，屬正常。
- 「角色」欄：台詞取 `speaker`；choice 與 `truthVoice` 取編號的最後一段。
- 匯出的 `voice-lines.json`，`text` 是要唸的文字：台詞取 `text`、choice 取 `prompt`、記憶對照取 `truth`。
