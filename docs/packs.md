# 怎麼做一個題材包

題材包決定一個「處境」（失智、聽損、憂鬱、轉學、新住民……）在遊戲裡怎麼呈現：啟用哪些效果、崩壞的程度怎麼隨幕變化、介面上的特殊文字，以及寫故事時的準則與注意事項。**新增題材包不需要改程式**，只要新增一個資料夾。

## 1. 建立資料夾

```
packs/
  hearing/            ← 代號：英文小寫，會寫在腳本的 meta.pack
    pack.json         ← 必要
    README.md         ← 這個題材包是什麼
    guide.md          ← 寫作準則（症狀與效果對照）
    cautions.md       ← 注意事項（避免的寫法、需要查證的地方、建議諮詢的對象）
```

## 2. 寫 pack.json

```json
{
  "name": "聽損",
  "description": "用第一人稱經歷聽力受損：對話越來越模糊，只能靠表情和猜測。",
  "effects": ["muffle", "text_blur", "focus_drift"],
  "degradation": [0, 0.4, 0.8],
  "texts": {
    "forgottenPerson": "那個人",
    "forgottenThing": "那個東西"
  },
  "docs": { "readme": "README.md", "guide": "guide.md", "cautions": "cautions.md" }
}
```

| 欄位 | 說明 |
| --- | --- |
| `name` | 顯示的名稱 |
| `description` | 一兩句說明 |
| `effects` | 啟用的效果標籤，從 11 種裡挑（見 README「效果標籤」）。不在清單裡的效果在遊戲裡不會出現，腳本檢查會提醒。空陣列＝沒有特殊效果。 |
| `degradation` | 退化係數隨幕變化：第 1 幕用第 1 個數字、第 2 幕用第 2 個……超過的幕沿用最後一個。0 是正常、1 是最嚴重。它影響打字的穩定度、可以點的物件有多明顯、音樂走音等。全部是 0＝沒有退化。 |
| `texts.forgottenPerson` | `name_fade` 時人名最後變成的字（預設「那個人」） |
| `texts.forgottenThing` | 物件說明卡 `name_fade` 時名稱最後變成的字（預設「那個東西」） |
| `docs` | 說明文件的檔名（之後的引導流程會讀它們放進提示詞） |

缺少或寫錯的欄位會用預設值（開發者面板與主控台會提醒）。

## 3. 在腳本裡使用

腳本的 `meta.pack` 寫題材包代號：

```json
{ "meta": { "title": "我的遊戲", "pack": "hearing", "stats": {} } }
```

- 省略 `meta.pack`：當作 `dementia`（相容舊腳本）。
- `"pack": "plain"` 或 `null`：一般故事，沒有特殊效果。
- 寫了不存在的代號：改用一般故事，主控台會提醒。

開發者面板「呈現調整」的「題材包」可以即時切換，按「儲存調整」寫進腳本。

## 4. 寫說明文件

參考 `packs/dementia/` 的三份文件：

- **README.md**：這個題材包讓玩家體會什麼、範例作品、效果與退化的設定。
- **guide.md**：寫作準則。最重要的是「症狀與效果對照」：想讓玩家體會的感受、用哪個效果、寫法提醒。
- **cautions.md**：避免的寫法、需要查證的地方與來源、建議諮詢的對象、給玩家的提醒。

做題材包時，請找有這個處境的人、家屬或專業人員一起看。

## 建置

建置時 `packs/` 整個複製到網站與離線版，並產生 `packs.json`（題材包清單）；離線版把每個 `pack.json` 寫進 html，雙擊開啟也讀得到。
