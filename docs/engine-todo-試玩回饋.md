## 1. 可以點的物件（hotspot）

**製作人的新決定：「找找看」時刻（探索模式）**。有角色時物件常被立繪擋住，手機上更嚴重，所以改成：在沒有角色的空場景，劇本可以放一個「找找看」的停頓。

- 台詞新欄位 `explore`（見給劇本 AI 文件 4-4）：顯示提示（例如「這裡好像有東西可以看看」），物件柔和發亮。
- 探索時**點背景不會推進劇情**（避免一直按繼續就跳過），畫面出現明確的「繼續」按鈕；玩家要繼續隨時可以按。
- 手機直式：提示「左右滑動看看」（已有拖曳背景），物件在畫面外時邊緣顯示箭頭。
- 有角色的時候，物件仍然可以點，但不期待玩家在那時找東西；`required` 的互動物件不放在角色身後。

## 橫式與直式（手機）會打架的地方

做每一項時都要在電腦橫式與手機直式各測一次。已知的衝突與決定：

| 功能 | 衝突 | 做法 |
| --- | --- | --- |
| 物件被立繪擋住 | 直式畫面窄，立繪佔大半 | 探索模式只在空場景；熱點層在立繪之上 |
| 物件在背景邊緣 | 直式只看得到背景中間 | 已有左右拖曳；探索時顯示箭頭；`required` 物件出現時自動平移到它 |
| 物件圖疊在背景（`overlayWidth`） | 直式時很小，手指點不到 | 點擊區最小 44px（與畫面大小無關） |
| 選項在對話框右上方 | 直式放不下 | 直式維持置中（已決定） |
| 說明卡不擋臉 | 直式沒有空間放旁邊 | 直式改成從下方滑出的卡片，照片可以放大 |
| 互動物件（手機）放左邊 | 直式左邊可能在畫面外 | 位置用背景座標，出現時自動平移；震動動畫尊重「減少動態」設定 |
| 章節卡、標題、場景小標題 | 字大小 | 用相對畫面大小的字級，兩種方向都看過 |
| 封面圖 | 直式裁切不同 | 封面以中間為主，`meta` 可另給直式封面（選填） |
| 暫停選單、工具列 | 直式按鈕擠 | 直式時工具列收進暫停選單 |
| 開發者面板拖曳物件、調選項位置 | 手機上很難操作 | 只保證電腦上可用；手機上可以看但不必能拖 |
| UI 樣式 2～3 種 | 每種都要適配 | 每種樣式都在兩種方向截圖檢查 |
| 發亮、提示動畫 | 觸控沒有滑鼠移過去的效果 | 提示不能依賴 hover |
