# 成效評估問卷格式（survey.json）

給寫問卷內容的 AI 或老師、單位。引擎只負責顯示與統計；題目內容放在這個檔案，隨時可以替換。

## 放在哪裡

和 `script.json` 放在同一個資料夾，例如 `examples/寫給未來的我/survey.json`。沒有這個檔案就沒有問卷，遊戲照常。

## 格式

```json
{
  "title": "幾個小問題",
  "intro": "匿名填寫，答案只存在這台電腦，不會傳到網路上。可以略過。",
  "pre": [
    { "id": "know", "text": "你覺得自己了解失智症嗎？", "type": "scale", "min": 1, "max": 5, "minLabel": "完全不了解", "maxLabel": "非常了解" },
    { "id": "role", "text": "你是？", "type": "choice", "options": ["學生", "家屬或照顧者", "醫護或長照人員", "其他"] }
  ],
  "post": [
    { "id": "know", "text": "你覺得自己了解失智症嗎？", "type": "scale", "min": 1, "max": 5, "minLabel": "完全不了解", "maxLabel": "非常了解" },
    { "id": "feel", "text": "玩完之後，你最想對身邊的長輩說什麼？", "type": "text" }
  ]
}
```

| 欄位 | 說明 |
| --- | --- |
| `title` | 問卷標題（選填） |
| `intro` | 開頭說明（選填）。建議寫清楚：匿名、只存在這台電腦、可以略過 |
| `pre` | 玩之前的題目（按「開始」後出現，可以略過） |
| `post` | 玩之後的題目（結局按「回到標題」時出現，可以略過） |

每一題：

| 欄位 | 說明 |
| --- | --- |
| `id` | 題目代號，只能用英文字母、數字、底線。匯出的表格欄名是 `pre_{id}`、`post_{id}`；玩前、玩後同一個 id 方便比較 |
| `text` | 題目文字 |
| `type` | `scale`（量表）、`choice`（單選）、`text`（簡答，最多 500 字） |
| `min`、`max` | 量表的範圍，預設 1～5，最多 11 格 |
| `minLabel`、`maxLabel` | 量表兩端的文字（選填） |
| `options` | 單選的選項，至少兩個 |
| `required` | `true`＝必答（預設不必答） |

建議：玩前、玩後各 2～4 題，一分鐘內填完。不要問姓名、學號、電話等可以認出個人的資料。

## 回答存在哪裡、怎麼看

- 每一次遊玩（按「開始」）一筆，存在這個瀏覽器的 localStorage，不會送出。
- 開發者面板「問卷結果」：回答數、量表平均、單選各選項人數；「匯出 CSV」可以用 Excel 或 Google 試算表打開；「清除回答」。
- 適合在活動現場用同一台電腦（或平板）讓很多人輪流玩，結束後匯出。

## 引擎實作補充

- 網站版：建置時 `projects.json` 的 `extras` 記下哪些專案有 `survey.json`，遊戲頁有記號才去讀，所以沒有問卷的專案不會出現 404。
- 離線版（`dist-offline/`）：問卷寫進 html；開發者面板「匯出可以玩的版本」也會把問卷帶進去。
- 本機專案（引導網站做的遊戲）目前不讀問卷。
- 格式有問題時，主控台警告，這次不顯示問卷（遊戲照常）。
