# 失智症題材包：寫作準則

給寫劇本的人（或寫劇本的 AI）。之後的引導流程會把這份準則放進各步驟的提示詞裡。

## 核心原則

1. **玩家是當事人，不是旁觀者。** 用第一人稱。玩家看到的就是主角感覺到的：主角以為是對的，畫面就照錯的演。
2. **崩壞要從「正常」開始。** 第一幕幾乎完全正常，讓玩家先相信這個世界；崩壞逐幕加重（退化係數 0 → 0.5 → 1）。
3. **不解釋症狀。** 不寫「她的記憶力變差了」，而是讓選項消失、讓名字變成底線，讓玩家自己發現。
4. **身邊的人也在努力。** 家人、同事的反應要真實：耐心、疲憊、假裝沒事、偶爾生氣。不要把照顧者寫成壞人，也不要寫成聖人。
5. **留下尊嚴。** 主角仍然是一個完整的人：有個性、有記憶裡最重要的東西、有想守住的事。結局不是「她忘了一切」，而是「她還記得什麼」。

## 症狀與效果對照

| 想讓玩家體會的 | 用哪個效果 | 寫法提醒 |
| --- | --- | --- |
| 叫不出熟人的名字 | `name_fade` | 名字變成底線、最後變成「那個人」，同時露出角色特徵（`trait`）。用在重要的人身上更痛。 |
| 讀不懂、看不清字 | `text_blur` | 用在主角正在讀的東西（便利貼、講稿、訊息），不要整段都用。 |
| 同一句話說兩次 | `repeat_line` | 用在主角自己的話。周圍的人第二次聽到時的反應可以寫出來。 |
| 想說的話來不及說 | `choice_vanish` | 選項出現後一個個消失。最重要的選項放在最後才消失，或最先消失。 |
| 不管說什麼都一樣 | `flat_options` | 所有選項同樣語氣，點哪個都走第一個選項的去向。用在主角失去判斷力的時刻。 |
| 東西不在該在的地方 | `wrong_object` | 眼鏡在冰箱、手上拿的不是原本的東西。搭配「可以點的物件」與記憶對照最有效。 |
| 時間錯亂、突然回到過去 | `time_skip` | 背景短暫切到另一個場景再切回。 |
| 世界失去顏色 | `desaturate` | 會累加、不會恢復，整個遊戲用三四次就夠。 |
| 注意力飄走 | `focus_drift` | 對話對象變糊，焦點飄到背景。 |
| 不知道自己在哪裡 | `look_around` | 視線無目的地左右移動。 |
| 聽不清楚、和世界隔了一層 | `muffle` | 聲音變悶，台詞變淡。 |

## 可以點的物件與記憶對照

- 物件的說明（`description`）用主角的口吻，**越後面越不可靠**：第一幕正確，第二幕可以說錯，第三幕只剩幾個字。
- 物件圖（`image`）與真相（`truth`）永遠是真的。結局的記憶對照會把主角當時說的和真相並排，讓玩家回頭發現「原來那時候我錯了」。
- 隱藏選項：要先點過某些物件才會解鎖的選項。用來獎勵仔細觀察的玩家，也讓「記得」變成一件需要努力的事。

## 長度建議

- 短篇（課堂作品）：約 5 分鐘、2 到 3 個場景、3 到 5 次選擇、每種效果最多用一兩次。
- 完整作品：10 到 20 分鐘、三到四幕。《寫給未來的我》約 16 分鐘、21 個場景、20 次選擇，遊玩字數約 4000 字。

## 格式

- 腳本格式見 `docs/script-format-v1.md`、`v2`、`v3-voice`。
- 腳本的 `meta.pack` 寫 `"dementia"`。
- 旗標用英文小寫加底線；隱藏選項的旗標以 `hidden_` 開頭。
